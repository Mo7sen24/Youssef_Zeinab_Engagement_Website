# Youssef & Zeinab Engagement Invitation

## Add your photos
Put these files inside the `images` folder:

- `hero.jpg` — main couple photo / background
- `youssef-childhood.jpg` — Youssef childhood photo
- `zeinab-childhood.jpg` — Zeinab childhood photo
- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

You can use fewer gallery photos if you want; the placeholders will remain for missing images.

## Change the event time
Open `script.js` and change:

EVENT_TIME = "20:00";
EVENT_TIME_LABEL = "8:00 PM";

The date is already set to 16 September 2026.

## RSVP
The current RSVP saves the response in the visitor's browser using localStorage. It does NOT send responses to you.

For real RSVP collection, connect the form to a service/backend such as Google Forms, Formspree, Firebase, Supabase, or your own API.

## Run
Open `index.html` in a browser.

For deployment, upload the folder to GitHub Pages, Netlify, or Vercel.
